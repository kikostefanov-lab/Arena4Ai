> **Historical design document, March 2026.** Written while the project was still called *Agent Arena* and planned as a commercial, hosted product. Arena4Ai is now self-hosted and open source: you run your own agent CLIs under your own auth, and there are no shared APIs and no model API keys. Cost tables, API-key sections, hosting plans and model ids below are **not current** and are kept only as a record of the original design. See `README.md` for how the project actually works today.

## Repository Overview

**Architecture:** Turborepo monorepo with 5 packages
**Language:** TypeScript (strict mode)
**Runtime:** Node.js 20+ (orchestrator, API), Bun (optional for adapters)
**Frontend:** Next.js 14+ (App Router), TailwindCSS, Radix UI
**Infra:** Docker (Phase 0), Firecracker microVMs (Phase 1+), NATS JetStream, PostgreSQL

## Core Type Definitions

### Universal Event Schema (`packages/shared/src/types/event.ts`)

```typescript
export type EventType =
  | 'COMPETITION_CREATED'
  | 'COMPETITION_CONFIGURED'
  | 'TEAM_LAUNCHING'
  | 'TEAM_READY'
  | 'EXECUTION_STARTED'
  | 'TOOL_CALL'          // Agent invoked a tool
  | 'TOOL_RESULT'        // Tool returned a result
  | 'FILE_CREATE'        // Agent created a file
  | 'FILE_MODIFY'        // Agent modified a file
  | 'FILE_DELETE'        // Agent deleted a file
  | 'REASONING'          // Agent's thinking/planning step
  | 'SUB_AGENT_SPAWN'   // Agent spawned a sub-agent
  | 'SUB_AGENT_RESULT'  // Sub-agent returned
  | 'ERROR'             // Agent encountered an error
  | 'TIME_WARNING'      // 80% of time budget consumed
  | 'TIME_UP'           // Time budget exhausted
  | 'DELIVERABLE_READY' // Team submitted final artifact
  | 'JUDGING_STARTED'
  | 'JUDGE_SCORE'
  | 'SCORING_COMPLETE'
  | 'SYNTHESIS_STARTED'
  | 'SYNTHESIS_COMPLETE'
  | 'FORGE_STARTED'
  | 'FORGE_COMPLETE'
  | 'COMPETITION_COMPLETE';

export interface ArenaEvent {
  eventId: string;              // UUID v7 (time-sortable)
  competitionId: string;        // UUID
  teamId: string | null;        // null for competition-level events
  timestamp: string;            // ISO 8601
  type: EventType;
  payload: Record<string, unknown>;
  metadata: {
    model?: string;             // provider id, e.g. 'claude', 'codex', 'gemini'
    adapterId?: string;         // Which adapter produced this event
    rawEvent?: unknown;         // Original model-specific event
    tokenUsage?: {
      input: number;
      output: number;
      cumulative: number;
    };
    latencyMs?: number;
    sequenceNumber: number;     // Monotonic per team per competition
  };
}
```

### Model Adapter Interface (`packages/shared/src/types/adapter.ts`)

```typescript
export interface ModelAdapter {
  /** Unique identifier for this adapter */
  readonly id: string;

  /** Human-readable name */
  readonly name: string;

  /** Which model this adapter supports */
  readonly model: string;

  /** Check if the model/service is available */
  healthCheck(): Promise<AdapterHealthStatus>;

  /** Initialize sandbox and inject brief */
  injectBrief(
    brief: Brief,
    persona: PersonaConfig | null,
    sandboxPath: string
  ): Promise<void>;

  /** Start execution — returns when agent begins working */
  startExecution(): Promise<void>;

  /** Subscribe to events from this adapter */
  onEvent(handler: (event: ArenaEvent) => void): void;

  /** Collect deliverables from sandbox after execution */
  collectDeliverables(sandboxPath: string): Promise<Deliverable[]>;

  /** Graceful shutdown — signal agent to wrap up */
  shutdown(reason: 'TIME_UP' | 'CANCELLED' | 'ERROR'): Promise<void>;

  /** Force kill — immediate termination */
  kill(): Promise<void>;
}

export interface AdapterHealthStatus {
  healthy: boolean;
  latencyMs: number;
  details?: string;
}

export interface Deliverable {
  name: string;
  path: string;
  sizeBytes: number;
  format: string;
  hash: string;                 // SHA-256 for integrity
}
```

### Orchestrator REST API (`packages/orchestrator/src/routes/`)

```
POST   /api/v1/competitions              → Create competition (Brief + Teams)
GET    /api/v1/competitions               → List competitions (paginated, filterable)
GET    /api/v1/competitions/:id           → Get competition detail + state
```

## Database Schema

### PostgreSQL (`packages/orchestrator/src/db/schema.ts`)

```sql
-- Competitions table
CREATE TABLE competitions (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  brief JSONB NOT NULL,
  teams JSONB NOT NULL,
  state VARCHAR(20) NOT NULL DEFAULT 'DRAFT',
  format VARCHAR(20) NOT NULL,
  results JSONB,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  started_at TIMESTAMPTZ,
  completed_at TIMESTAMPTZ,
  created_by VARCHAR(255)
);

-- Events table (append-only event store)
CREATE TABLE events (
  event_id UUID PRIMARY KEY,
  competition_id UUID NOT NULL REFERENCES competitions(id),
  team_id VARCHAR(100),
  timestamp TIMESTAMPTZ NOT NULL,
  type VARCHAR(50) NOT NULL,
  payload JSONB NOT NULL,
  metadata JSONB NOT NULL,
  sequence_number INTEGER NOT NULL
);

CREATE INDEX idx_events_competition ON events(competition_id, timestamp);
CREATE INDEX idx_events_team ON events(competition_id, team_id, timestamp);
CREATE INDEX idx_events_type ON events(competition_id, type);

-- Score cards
CREATE TABLE score_cards (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  competition_id UUID NOT NULL REFERENCES competitions(id),
  team_id VARCHAR(100) NOT NULL,
  judge_id VARCHAR(100) NOT NULL,
  judge_type VARCHAR(20) NOT NULL,
  scores JSONB NOT NULL,
  overall_score NUMERIC(4,2) NOT NULL,
  commentary TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Forge outputs
CREATE TABLE forge_outputs (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  competition_id UUID NOT NULL REFERENCES competitions(id),
  output_type VARCHAR(50) NOT NULL,  -- roadmap, task_graph, blueprint, etc.
  content TEXT NOT NULL,
  metadata JSONB,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Artifacts (deliverables stored as references)
CREATE TABLE artifacts (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  competition_id UUID NOT NULL REFERENCES competitions(id),
  team_id VARCHAR(100) NOT NULL,
  name VARCHAR(255) NOT NULL,
  storage_path VARCHAR(500) NOT NULL,
  size_bytes BIGINT NOT NULL,
  hash VARCHAR(64) NOT NULL,
  created_at TIMESTAMPTZ DEFAULT NOW()
);
```
